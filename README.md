# Hushfacebook Build

Automated GitHub Actions builds of patched Facebook APKs using [Hushfacebook](https://github.com/SysAdminDoc/Hushfacebook) and [morphe-desktop](https://github.com/MorpheApp/morphe-desktop).

Download the latest APK from [Releases](https://github.com/takattowo/Hushfacebook_Build/releases).

## Credits

- [Hushfacebook](https://github.com/SysAdminDoc/Hushfacebook) - the patches (GPL-3.0)
- [Morphe](https://github.com/MorpheApp) - patcher and desktop CLI (GPL-3.0)
- This repo only automates building; it adds no patches of its own.
